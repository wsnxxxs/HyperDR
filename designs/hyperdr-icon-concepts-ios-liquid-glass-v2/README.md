# HyperDR 图标候选（低饱和 Liquid Glass）

这组候选按最终约束制作：iOS/macOS 统一的圆角方形构图、扁平液态玻璃质感、低饱和配色、每枚不超过三种主色、少量大形状、无文字。

| 编号 | 方向 | 视觉重点 |
| --- | --- | --- |
| 01 | Slate Diamond | 冷静的蓝灰底，双菱形叠层，最技术化 |
| 02 | Sage Arc | 鼠尾草绿与象牙白弧面，最柔和、最系统化 |
| 03 | Navy Loop | 深海军蓝底，中央留白环，辨识度高 |
| 04 | Rose Wedge | 暗玫瑰三角与象牙楔形，温和但有存在感 |
| 05 | Olive Crossing | 橄榄绿底，双胶囊交叠，几何感最强 |
| 06 | Mauve Chevron | 灰紫底，单条纵向折带，轻盈简洁 |
| 07 | Teal Overlap | 石色底，青绿色与象牙圆面叠加，最克制 |
| 08 | Diagonal Plane | 炭黑底，斜向雾面玻璃板，专业、对比明确 |
| 09 | Clay Notch | 陶土红底，双横向圆角板与中央缺口，温暖稳重 |
| 10 | Terracotta Cutout | 灰蓝底，陶土色主形配单一圆形切口，最有个性 |

选定其中一枚后，再将它导出为 iOS、macOS、Windows 所需尺寸并接入现有图标资源；本目录候选不会覆盖现有应用图标。
