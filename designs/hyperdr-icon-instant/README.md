# 拍立得：图标变体与 Icon Composer 分层

把装裱方向（[hyperdr-icon-frame-mat](../hyperdr-icon-frame-mat/README.md)）做成一次成像相纸的样子：深色底上放一张白色相纸，照片里还是那个光点悬在白线上方。相纸用方形相纸的比例：卡片 72 × 86，画面 62 × 62，两侧 5、顶部 6.5，其余留在底边。认出“拍立得”主要靠这条宽底边，所以没有用任何品牌的彩条或字样。

| 变体 | 构图 | 特点 |
| --- | --- | --- |
| P1 正放 | 一张相纸端正放在中间 | 最克制，最像一个符号 |
| P2 微倾 | 同一张相纸逆时针转 7° | 最有“刚拍出来”的手感，主屏上最活泼 |
| P3 显影 | 相纸还是灰绿色，只有光点已经显出 | 讲了一个故事：高光最先出现；没有横线，最简洁 |
| P4 叠放 | 前面一张转 −3°，后面一张空白相纸转 7° | 最有实物感，细节也最多 |

试过把整个图标当成一张相纸（满幅），但正方形装不下宽底边的比例，看起来就是装裱方案，已删掉。

## 文件

- `<变体>/layers/`：给 Icon Composer 用的图层，每个文件是一张 1024 × 1024 的 SVG，只有一个纯色图形。倾斜已经算进坐标，导入后不需要再旋转。文件名的数字就是从后往前的顺序。
- `<变体>/preview-light.svg`、`preview-dark.svg`：合成预览，带近似的圆角遮罩和相纸阴影，只用来看效果，不要导入。
- `preview.html`：四个变体在浅色和深色下的 256 / 120 / 60 / 29 px 效果和主屏效果。
- `make_icons.py`：生成以上所有文件；尺寸、角度和颜色都在脚本里，改完运行 `python3 make_icons.py`。`preview.html` 由 `preview.template.html` 生成。

## 导入 Icon Composer

1. 新建文档，把选中变体 `layers/` 里的 SVG 拖进侧栏。
2. 分两组：相纸（P4 还有后面那张）一组，照片、横线和光点一组。相纸组打开阴影，让它像放在桌上的一张实物；照片组放在它上面。
3. 底色不是图层：在文档的背景填充里设为 `#22211F`，深色外观设为 `#0E0E0D`。
4. 在深色外观下，按上表逐个覆盖图层的填充色。
5. 只给光点留最强的高光。相纸可以开很弱的 Liquid Glass，表现相纸边缘的反光；照片不要开，保持哑光。
6. 单色（着色）外观由系统生成，导入后检查相纸和底色是否还分得开。

本目录只是设计稿，没有改动应用的图标设置。
