# Documentation index

Every document in the repository, by who it is for. Guides that belong to a
directory stay in that directory — a README beside the code it describes is how
it gets found — so this page links out rather than collecting copies.

## 语言约定 / Language

面向**使用者与操作者**的指南用中文：面板、iPhone LAN、前端说明、借机执行手册。
面向**贡献者**的架构、参考与流程文档用英文：README、CONTRIBUTING、项目结构、
CLI 与报告参考、打包、HyperDR_Model。

新增文档时按这条规则选语言；如果一份文档同时服务两类读者，按它的主要读者归类，
不要写成半中半英。

`tests/js/curve-math` note: `apps/panel/web/js/preview/curve-math.js` is a direct
port of the C++ tone curve, and CI compares all 257 of its samples against the
freshly built converter. Since the native float preview landed it is **exercised
only by `tests/js/curve_math_runner.mjs`** — no shipped panel code imports it. It
is kept as the parity guard for when a browser-side curve is wanted again; do not
read it as live render code.
