# 装裱：图标变体与 Icon Composer 分层

这组变体都基于图标方向 C：米色衬纸上一张深色照片，照片里一个白色光点悬在灰色横线上方，表示高光超出了普通显示的白。照片都放在光学中心偏上，下方衬纸留得最宽，和导出时的装裱边框一致。

| 变体 | 照片 | 特点 |
| --- | --- | --- |
| C1 方幅 | 方形照片，带图注 | 最平衡，作为基准 |
| C2 横幅 | 3:2 横幅，光点偏右，带图注 | 最像一张照片，构图更生动 |
| C3 竖幅 | 4:5 竖幅，无图注 | 照片面积最大，小尺寸最清楚 |
| C4 宽边 | 小照片配大面积衬纸，带图注 | 最有画廊感，但小尺寸偏弱 |

## 文件

- `<变体>/layers/`：给 Icon Composer 用的图层，每个文件是一张 1024 × 1024 的 SVG，只含一个纯色图形。文件名的数字就是从后往前的顺序：`1-photo`、`2-horizon`、`3-caption`（C3 没有）、`4-light`。
- `<变体>/preview-light.svg`、`preview-dark.svg`：带近似圆角遮罩的合成预览，只用来看效果，不要导入。
- `preview.html`：四个变体在浅色和深色下的 256 / 120 / 60 / 29 px 效果，以及放在主屏上的样子。
- `make_icons.py`：生成以上所有文件。尺寸和颜色都在脚本顶部，改完运行 `python3 make_icons.py` 即可。`preview.html` 由 `preview.template.html` 生成。

## 颜色

| 元素 | 默认外观 | 深色外观 |
| --- | --- | --- |
| 衬纸（文档背景） | `#EEEBE5` | `#262523` |
| 照片 | `#141414` | `#0A0A0A` |
| 横线 | `#6E6E73` | `#5A5A5E` |
| 光点 | `#FFFFFF` | `#FFFFFF` |
| 图注 | `#A39F96` | `#6A665F` |

## 导入 Icon Composer

1. 新建文档，把选中变体 `layers/` 里的 SVG 拖进侧栏。
2. 分成两组：前面一组只放 `4-light`，后面一组放照片、横线和图注。
3. 衬纸不是图层：在文档的背景填充里设为纯色 `#EEEBE5`，深色外观设为 `#262523`。
4. 在深色外观下，按上表逐个覆盖图层的填充色。
5. 光点所在的组打开 Liquid Glass 和高光，让它成为全图最亮、最“立体”的地方；照片那组关掉玻璃效果，或者只留很弱的透明度，让它保持像一张印出来的照片。
6. 单色（着色）外观由系统根据亮度生成，导入后检查一遍光点是否仍然最突出。

本目录只是设计稿，没有改动应用的图标设置。
