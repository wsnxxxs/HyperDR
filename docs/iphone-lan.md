# 手机连接工作台

电脑负责编辑和处理，手机负责导入、同步预览和保存成品。手机使用独立的
/phone 页面，不加载桌面编辑器的布局、调节栏或状态持久化逻辑。

## 使用流程

1. 打开 HyperDR 桌面应用，或双击 Start.bat 打开本机编辑器。
2. 点击标题栏的 **连接手机**。手机和电脑连接同一 Wi-Fi，扫描二维码。
   独立向导按实际状态显示「连接手机 → 选择照片 → 同步预览」，连接成功后收起二维码。
   多网卡电脑可以展开 **连接遇到问题？** 切换地址或关闭连接；Windows 防火墙应允许程序在专用网络通信。
   关闭向导或按 Escape 不会断开连接，可以继续在电脑编辑。
3. 手机选择 **从相册选择** 或 **从文件选择**。照片直接上传到运行 HyperDR 的电脑，
   无需先通过其他软件传文件。上传完成后，电脑自动载入这张照片。
4. 在电脑调整参数，手机自动显示更新后的画面。手机支持按住看原图、双指缩放、
   拖动、适合屏幕和全屏预览。新画面就绪前保留旧画面，并明确显示更新状态。
5. 在电脑导出。完成后手机的 **完成的照片** 列表提供 **保存到手机**。
   保存的是正式导出的文件，不是预览截图；浏览器通常先保存到下载目录，
   如需放进系统相册，再通过系统分享菜单保存。
6. 手机点 **换一张照片**，或在电脑导入另一张。两端一起切换，无需再次扫码。
   本次服务运行期间的最近 30 个成品仍可下载。

手机刷新或暂时离开页面后，会重新订阅当前照片和预览。电脑编辑器刷新也会恢复
本标签页的连接。关闭连接或重启处理服务后，需使用新二维码；不会保留长期配对凭据。
短暂断网会自动重试，也可点击 **重试连接**。切到后台会暂停连接初始化与重试，返回前台后恢复；口令失效时提示重新扫码。
上传被打断时可以取消未完成的上传并重新选择，暂不支持断点续传。

一次编辑一张照片。电脑导出、AI 优化或任一端上传期间暂不接受换图。
手机只操作导入、查看和下载，画面参数由电脑统一编辑。

## HDR 与 HTTPS

普通 HTTP 连接支持手机上传、SDR 预览和成品下载。真 HDR 画布需要：

- 受信任的 HTTPS 安全上下文；
- 支持 WebGPU HDR 的浏览器与 HDR 屏幕；
- 运行时通过扩展 Display P3 浮点画布校验。

不满足条件时，页面明确标记 **SDR 预览**，正式 HDR 导出不受影响。

### 在工作台中首次配置

1. 在电脑打开 **连接手机 → HDR 可在连接后设置 → 开启 HDR 预览**。应用在后台生成本机独立根证书和服务器证书，不需要 mkcert、winget 或电脑管理员授权，也不修改电脑系统信任。
2. 扫描 **首次设置** 二维码。安装助手自动识别 iOS / Android，也可以手动切换。
3. iPhone / iPad：用 Safari 下载描述文件，在“设置 → 已下载描述文件”（或“通用 → VPN 与设备管理”）安装；然后在“通用 → 关于本机 → 证书信任设置”开启对应根证书的完全信任。安装与信任是两个独立步骤，网页不能代办。
4. Android：下载 `.crt`，在系统设置搜索“安装证书”，选择 **CA 证书**并选取文件。不要选择 WLAN 或 VPN/应用证书；不同厂商菜单名称可能不同。
5. 返回安装助手，点击 **检查并进入工作台**。手机检查安全上下文、WebGPU、HDR 显示能力和实际浮点渲染器，并将结果同步到电脑。没有照片也能完成检测；照片加载后，画面标记显示实际预览模式。

普通 HTTP 预览始终可选。证书配置成功不等于设备支持 HDR；屏幕或浏览器不支持时继续提供 SDR 预览和正常导出。不要用“忽略证书警告”代替安装信任。

首次设置入口是独立、限时 15 分钟的 HTTP 服务，只提供公开根证书、安装说明和进入 HTTPS 的跳转。它使用独立口令，不提供照片、上传或电脑控制接口。手机通过 HTTPS 回报安全上下文后入口关闭；新手机可在电脑点击 **设置另一部手机**重新开启。

安装助手取得地址后，**检查并进入工作台**会直接打开 HTTPS。下载入口结束后，已打开的助手仍可尝试上次取得的地址；只要预览服务未重启或切换，无需重新安装证书或重启连接。若地址已变化，请扫描电脑上的新二维码。

请只安装自己电脑生成的证书，并核对电脑高级设置与手机页的 SHA-256 指纹。根证书信任属于系统信任，并非仅对 HyperDR 生效。私钥始终留在电脑，不包含在下载文件或发布包内。

### 地址变化与续期

连接时会检查所有候选地址和有效期，受管服务器证书临近到期或地址变化时自动续签，保留原根证书。切换监听服务保留电脑照片、调整和导出记录；手机正在上传或等待电脑接收时，完成交接后再切换。切换后扫描新的连接二维码。

证书位于 `%LOCALAPPDATA%\HyperDR\tls`，新根证书位于其 `ca` 子目录。能验证签发关系的旧 mkcert 根证书会继续复用；缺失原根证书或私钥时给出恢复说明，不会静默更换手机已信任的 CA。外部 `HYPERDR_TLS_CERT` / `HYPERDR_TLS_KEY` 路径视为只读配置；指向标准受管路径的环境变量仍可自动维护。

旧入口 `Setup-HTTPS.bat` 也使用同一证书管理器，可准备证书并导出公开 `.crt`；不再安装 mkcert。源码运行时，证书功能需要先执行 `python -m pip install -r apps/panel/requirements.txt`；桌面发布版随应用打包依赖。没有此依赖时仍可使用普通 HTTP 工作台。

### 排查与移除

- 连不上电脑：检查同一 Wi-Fi、是否处于隔离的访客网络、电脑地址选择和专用网络防火墙。
- 扫码后出现 `token_required`：旧版登录 Cookie 可能在浏览器跳转时被拦截。更新到包含此修复的版本并重启电脑应用，再扫描新二维码；已安装且仍有效的证书无需重新安装。
- HTTPS 未验证：确认安装了对应电脑的根证书；iOS 再检查完全信任开关。网页无法读取系统证书列表，未收到结果只表示尚未完成验证。
- 安全连接正常但使用 SDR：在手机重新检测；更新系统/浏览器后再试，成品导出不受影响。
- 不再使用：iOS 在“通用 → VPN 与设备管理”移除对应 HyperDR 描述文件；Android 在安全设置的用户凭据/受信任凭据中只移除对应 HyperDR CA。电脑先关闭手机连接，再按需删除本机 HyperDR 专属 `tls/ca` 与服务器证书；不要删除其他应用共用的旧 mkcert CA。删除根证书后重新生成，需要重新配置手机信任。

## 实现结构

- 本机编辑器默认监听 127.0.0.1:8756；连接按钮按需开启独立的局域网服务，
  优先使用 8757，占用时自动选择其他端口。关闭连接会停止该监听器。
- hyperdr_panel/workbench.py 保存共享照片、参数、上传交接和成品记录。
  每次只有一个桌面窗口控制工作台；另一个窗口显式连接时会接管。
- web/js/ui/phone-workbench.js 负责桌面连接窗口、分阶段二维码、证书配置和检测状态。
- hyperdr_panel/phone_tls.py 负责证书生命周期；phone_connection.py 管理监听服务切换，phone_setup.py 提供限时安装入口。
- web/phone/setup.* 提供手机安装助手，js/preview/phone-diagnostics.js 复用实际 HDR 渲染校验。
- web/phone/ 是独立的手机 HTML、CSS 和 JavaScript，使用 SSE 接收状态更新。
- 手机直接领取电脑已生成的原生预览包，不发起第二次 RAW 渲染。两端只共享
  二进制解析和 HDR / SDR 渲染底层，手机不加载桌面编辑器。
- 手机服务使用独立口令，不能调用桌面文件路径、调参或启动转换接口；
  下载仅限本工作台已发布的成品。

任务文件仍存于 hdr-workspace，默认空闲 24 小时后清理。默认单文件上限
512 MB，可通过 HYPERDR_MAX_UPLOAD_MB、HYPERDR_MAX_SESSION_MB 和
HYPERDR_SESSION_HOURS 调整。手机列表中的过期结果需重新导出。
