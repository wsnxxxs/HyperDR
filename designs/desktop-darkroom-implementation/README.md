# 暗房前端落地验证

2026-09-06 更新。实际入口为 `apps/panel/web`，Tauri 与浏览器面板共用；参考已确认的 `desktop-darkroom-demo`。绿色主题改为中性灰和蓝色强调色。

## 布局

- 顶部操作栏、左侧大画布；直方图与调整控件在右栏一起滚动。
- 顶部与侧栏融入连续应用框架；照片预览区保留内嵌圆角边界。浅色使用中性浅灰画布，暗色使用深灰画布。导入空白状态随主题变化，隐藏不可用的编辑控件，侧栏呈现简短三步引导。
- Windows 窗口按钮合并到应用顶栏，移除原生鲜蓝标题栏。窗口操作仅向本地面板开放四项必要权限，浏览器模式保持普通顶栏。
- 无左侧工具栏，无常驻右下输出设置。
- 导出采用约 840×628 的横向弹窗（含已有结果）。六种格式三列两行；当前色域在左、sRGB 限缩在右，质量为滑块。
- 导出成功结果放在左栏，包含真实元数据和下载。顶部版本卡片可下载独立文件或恢复参数。
- 默认暗色；保留浅色、系统主题以及中英文切换。

## 本轮整页优化

- 统一灰蓝色控件、Phosphor 本地图标、细滑轨、紧凑读数与折叠分组。右栏使用单一滚动区域。
- 画布增加照片信息和分屏标签；底部集中视图与缩放，空白导入区、快捷键、偏好与版本记录采用一致样式。
- 手动模式保留三个主要滑块，作用区域与高光恢复默认展开；AI 模式保留三个主要滑块，四个次要参数收进细节微调。
- 导出预览与设置分栏，进度和主操作横跨底部。当前色域优先、六种格式三列两行。
- 增加当前调整的导出状态，参数修改和撤销会同步更新；有照片时单击画布不再误开文件选择。

“当前色域”表示保留会话当前工作色域，不额外限缩；现有新会话默认 sRGB，既有 P3/Rec.2020 会话和导出参数仍可恢复。缩放百分比相对于适应窗口；不表示源文件原始像素的 1:1 显示。
