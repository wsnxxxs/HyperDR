# HyperDR SVG 标识方向

当前版本的炭黑底、银白与蓝色斜面符合摄影暗房的气质。主要改进机会在于：现有色带延伸至图标边缘，轮廓更接近装饰性切片；品牌识别较依赖配色与材质，和 HyperDR 名称、HDR 影像处理之间的联系较弱。

本组沿用现有视觉语言，降低蓝色饱和度，以更完整的几何形状探索品牌标识。

| SVG | 方向 | 判断 |
| --- | --- | --- |
| [01-layered-light.svg](01-layered-light.svg) | 叠光：两片完整的光学薄片 | 推荐。延续性最好，但仍偏抽象；中央暗缝保留小尺寸分离度。 |
| [02-light-bridge.svg](02-light-bridge.svg) | 光桥：双立柱与斜桥形成 H | 名称关联更明确，但单字母标识本身较常见。 |
| [03-open-range.svg](03-open-range.svg) | 光域：光片越过开放取景框 | 影像语义更直观，但容易让人联想到通用编辑图标。 |

[comparison.svg](comparison.svg) 为三个方向的大图与 16 / 24 / 32 / 48 px 对照。PNG 文件由对应 SVG 渲染，便于直接预览。

所有图形均为手绘 SVG 矢量元素，无嵌入位图或外部资源。单独的图标不依赖字体；对比板文字使用系统字体。已通过 XML 解析检查，并用 resvg 渲染、人工查看对比板，未增加应用测试。

这组文件为设计候选，未接入或替换应用现有资源。
