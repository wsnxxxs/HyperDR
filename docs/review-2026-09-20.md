## 本次修复

| 问题 | 影响和修复 |
| --- | --- |
| AI 预览覆盖原片的 HDR 类型 | 增益图照片在 AI 模式读取 SDR 底图，之前把该输入域写回原片状态，影响重置和 Adaptive 导出位深。`apps/panel/web/js/preview/stage.js` 改为保留无调整参考帧识别的原片类型，状态提示使用同一来源。 |
| 预览入口保留客户端内部模型 ID | `apps/panel/hyperdr_panel/api.py` 与导出入口一致，清除客户端 `_model_id`，由正式模型选择解析结果提供内部 ID。 |
| 国际化检查阻断前端检查流程 | `scripts/check_panel_i18n.py` 未识别动态拼接的 `model.*` 和 `field.*` 翻译键。补齐已有动态键族声明，保留其他检查。 |
| 研究模型工具依赖运行目录 | 导出到仓库外会触发 `relative_to()` 异常，验证工具从其他目录启动时无法正确定位部分资产。修复两个脚本的路径处理，仓库内清单路径统一为相对路径。模型权重和哈希未改变。 |
| DNG 增益图尺寸乘法溢出 | 三个尺寸相乘可能先溢出再通过容量检查，接受空增益表并在解码时越界。把现有容量限制移至最后一次乘法之前，增加一个精确复现该错误的回归用例。 |
