# 手机连接向导

按用户选择的第二张概念图实现，真实入口为 `apps/panel/web`，桌面外壳与浏览器共用。

- 标题栏直接打开独立向导；偏好设置保留跳转入口。
- 左侧「连接手机 → 选择照片 → 同步预览」跟随服务端状态自动更新。
- 连接后收起二维码；上传时显示进度，断线显示重连提示。
- HDR 作为次级入口，保留证书准备、首次设置二维码、连接二维码和普通预览。
- 网络地址、刷新与关闭连接放在连接帮助中。关闭窗口或按 Escape 保持连接。
- 中英文、深浅色与窄屏布局均适配。

`reference.png` 为选定的 ImageGen 概念图；`desktop.png`、`light.png`、`narrow.png` 为实际界面；`comparison*.png` 为视觉核对。检查范围与未验证项见仓库根目录 `design-qa.md`。
