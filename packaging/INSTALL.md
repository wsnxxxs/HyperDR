# HyperDR on Apple platforms

HyperDR requires macOS 26 on Apple Silicon or iOS/iPadOS 26. Build the native
apps using the Xcode and package instructions in README.md and
apps/apple/README-iOS.md. The engine is linked statically through C ABI 5;
there is no separate CLI distribution.

Windows development is frozen at
[`6949167`](https://github.com/wsnxxxs/HyperDR/tree/6949167).
