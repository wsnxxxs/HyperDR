# 掠光：流动形态细化

用户认可第二轮「掠光」，希望增强流动感、减少字母 C 的联想。本轮保留银白与蓝灰的光学弧面，调整轮廓长宽、端点方向和曲面的宽窄变化。

- [01-swept-arc.svg](01-swept-arc.svg)：舒展。上端向右上方拉长，下端回收；最接近获认可的原案，建议优先继续细化。
- [02-turning-light.svg](02-turning-light.svg)：回流。上下曲面偏心错位，尾部向左下方展开，强调回旋趋势。
- [03-flowing-ribbon.svg](03-flowing-ribbon.svg)：流带。两端朝相反方向伸展，流动感更强，但会产生字母 S 的联想。

[comparison.svg](comparison.svg) 展示三种流动程度，以及 16 / 24 / 32 / 48 px 的缩小效果。所有 PNG 均从对应 SVG 渲染。
