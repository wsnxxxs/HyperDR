# 掠光 × 月光

沿着用户认可的「掠光」方向，将月光感融入流动弧面：柔银白亮面、冷蓝暗部、深夜蓝底，以及斜向舒展的收尾。继续考虑此前关于流动不足、像字母 C 的反馈。

| 原稿 | 取向 | 判断 |
| --- | --- | --- |
| [01-moon-arc.svg](01-moon-arc.svg) | 月弧：更明确的月牙 | 静谧、易理解，但仍有 C 的联想。 |
| [02-moon-flow.svg](02-moon-flow.svg) | 月流：月牙延伸成光尾 | 建议优先细化，兼顾月色与此前的流动方向。 |
| [03-moon-halo.svg](03-moon-halo.svg) | 月晕：淡月盘与微光晕 | 更有夜色氛围，月盘细节在小尺寸下会减弱。 |

[comparison.svg](comparison.svg) 展示三个方向及 16 / 24 / 32 / 48 px 对照。PNG 均由对应 SVG 通过 resvg 渲染。

所有形状、渐变和光晕均为 SVG 矢量元素，没有嵌入位图或外部依赖。已检查 XML 解析并人工查看渲染对比板。本轮仍为设计候选，未替换应用图标。
